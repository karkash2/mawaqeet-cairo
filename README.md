# مواقيت الصلاة - القاهرة (تطبيق أندرويد)

تطبيق بسيط يعمل بدون إنترنت، يحسب مواقيت الصلاة بتوقيت القاهرة بطريقة الهيئة المصرية العامة للمساحة،
بتصميم ذهبي زخرفي على خلفية سوداء. الواجهة في `app/src/main/assets/index.html`.

## طريقة 1: بناء الـ APK بدون تسطيب أي شيء (GitHub Actions)

1. أنشئ مستودعًا جديدًا على GitHub وارفع محتويات هذا المجلد بالكامل (بما فيه `.github`).
2. افتح تبويب **Actions** ثم **Build APK** ثم **Run workflow**.
3. بعد دقائق نزّل الملف من **Artifacts** باسم `mawaqeet-cairo-apk` وفك الضغط لتحصل على `app-debug.apk`.
4. انقله للموبايل وثبّته (فعّل "التثبيت من مصادر غير معروفة" إذا طلب الهاتف).

## طريقة 2: Android Studio

1. افتح Android Studio ثم **Open** واختر هذا المجلد وانتظر انتهاء الـ Sync.
2. من القائمة: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
3. الملف الناتج في `app/build/outputs/apk/debug/app-debug.apk`.

## طريقة 3: سطر الأوامر

مع تثبيت JDK 17 وAndroid SDK (منصة 34):

```
gradle assembleDebug
```

## تغيير المدينة

عدّل المتغيرات في أعلى السكربت داخل `index.html`: `LAT` و`LNG` و`TZ` وزوايا الفجر والعشاء.
